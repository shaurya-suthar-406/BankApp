🏦 Bank Management System (Java Console Application)
📌 Overview
This is a console-based Bank Management System built using Java.
It demonstrates Object-Oriented Programming (OOP) concepts along with basic banking features like account creation, login security, transactions, and balance management.

🚀 Features

👤 Account Management :
User Signup (Create account)
Login using Name & MPIN
Multiple accounts stored in memory

💰 Banking Operations :
Deposit money with validation
Withdraw money with balance check
View current balance

📜 Transaction History :
Records all deposits and withdrawals
Displays complete transaction history with balance updates

🔐 Security Features :
Login attempt limit (3 attempts)
Account access blocked after multiple failed login attempts

🧠 Concepts Used :
Object-Oriented Programming (OOP)
Classes and Objects
Encapsulation (basic level)
ArrayList (data storage)
Loops and Conditionals
Scanner for input handling

🛠️ Tech Stack :
Language: Java
IDE: Eclipse IDE
Type: Console Application
